Add @happyvertical/accounting package for multi-provider accounting integration.

Features:
- QuickBooks Online provider with full AR/AP support
- Customer, Invoice, Vendor, Bill, and Payment operations
- Push, pull, sync, and list capabilities
- Audit/reconciliation with field-level comparison
- OAuth token management with refresh callback
- HMAC-SHA256 webhook signature verification
- Pagination support for large datasets
- Timeout and retry with exponential backoff
- Local date handling to prevent timezone issues
