# SvelteKit Plugin

The SMRT SvelteKit plugin automatically generates API routes from your SMRT objects, providing a complete REST API with zero configuration.

## Overview

The SvelteKit plugin:
- **Scans your codebase** for SMRT objects decorated with `@smrt()`
- **Generates API routes** automatically in `src/routes/api/`
- **Creates configuration** file for centralized service management
- **Supports custom actions** beyond standard CRUD operations
- **Uses $lib aliases** for clean imports
- **Updates .gitignore** to exclude generated files

## Installation

```bash
npm install @have/smrt
# or
pnpm add @have/smrt
# or
bun add @have/smrt
```

## Configuration

### Basic Setup

Add the plugin to your `vite.config.ts`:

```typescript
import { sveltekit } from '@sveltejs/kit/vite';
import { smrtPlugin } from '@have/smrt/vite-plugin';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [
    sveltekit(),
    smrtPlugin({
      include: ['src/lib/smrt/**/*.ts'],    // Where to look for SMRT objects
      exclude: ['**/*.test.ts'],             // Files to exclude
      generateTypes: true,                   // Generate TypeScript declarations
      hmr: true,                             // Enable hot module replacement
      baseClasses: ['SmrtObject']            // Base classes to scan for
    })
  ]
});
```

### Plugin Options

```typescript
interface SmrtPluginOptions {
  // File scanning
  include?: string[];              // Glob patterns for files to scan
  exclude?: string[];              // Glob patterns for files to exclude
  baseClasses?: string[];          // Base class names to look for

  // SvelteKit integration
  svelteKit?: boolean;             // Enable SvelteKit route generation (default: true)
  routesDir?: string;              // Output directory for routes (default: 'src/routes/api')
  objectsDir?: string;             // Location of SMRT objects (default: 'src/lib/smrt')

  // Configuration generation
  configPath?: string;             // Config file directory (default: 'src/lib/server')
  configFileName?: string;         // Config file name (default: 'smrt.ts')

  // Type generation
  generateTypes?: boolean;         // Generate TypeScript declarations (default: true)
  typesDir?: string;              // Output directory for types

  // Development
  watch?: boolean;                 // Watch for file changes (default: true)
  hmr?: boolean;                   // Enable hot module replacement (default: true)
}
```

## Generated Routes

The plugin generates routes based on your SMRT object configuration.

### Standard CRUD Routes

For an object like:

```typescript
@smrt({
  api: true  // Enable all standard routes
})
class Document extends SmrtObject {
  title: string = '';
  content: string = '';
}
```

**Generated routes:**
```
src/routes/api/documents/
├── +server.ts              # GET (list), POST (create)
└── [id]/
    └── +server.ts          # GET (get), PUT (update), DELETE (delete)
```

### Route Endpoints

**Collection routes** (`/api/documents`):
- `GET /api/documents` - List all documents
  - Query params: `?limit=50&offset=0`
  - Returns: `{ items: [], count: number, limit: number, offset: number }`
- `POST /api/documents` - Create new document
  - Body: `{ title: "...", content: "..." }`
  - Returns: Created document with 201 status

**Item routes** (`/api/documents/[id]`):
- `GET /api/documents/:id` - Get specific document
  - Returns: Document object or 404
- `PUT /api/documents/:id` - Update document
  - Body: `{ title: "Updated" }`
  - Returns: Updated document
- `DELETE /api/documents/:id` - Delete document
  - Returns: `{ success: true }`

### Selective Route Generation

Control which routes are generated:

```typescript
@smrt({
  api: {
    include: ['list', 'get', 'create'],  // Only these routes
    exclude: ['delete']                   // Skip delete route
  }
})
class Document extends SmrtObject {
  // Only list, get, and create routes will be generated
}
```

**Available standard actions:**
- `list` - GET collection
- `get` - GET single item
- `create` - POST to collection
- `update` - PUT to item
- `delete` - DELETE item

## Centralized Configuration

The plugin generates a centralized configuration file on first run.

### Generated Configuration File

**Location:** `src/lib/server/smrt.ts`

```typescript
/**
 * Centralized SMRT configuration with per-object overrides
 * Generated by @have/smrt vite plugin
 */

import { ObjectRegistry } from '@have/smrt';
import type { SmrtClassOptions } from '@have/smrt';

/**
 * Per-object configuration overrides
 */
const objectOverrides: Record<string, Partial<SmrtClassOptions>> = {
  // Add your per-object configuration overrides here
};

/**
 * Default configuration for most SMRT objects
 */
function getDefaultConfig(): SmrtClassOptions {
  return {
    db: {
      url: process.env.DATABASE_URL || ':memory:',
      type: (process.env.DATABASE_TYPE as 'sqlite' | 'postgres') || 'sqlite'
    },
    ai: process.env.OPENAI_API_KEY ? {
      type: 'openai',
      apiKey: process.env.OPENAI_API_KEY
    } : process.env.ANTHROPIC_API_KEY ? {
      type: 'anthropic',
      apiKey: process.env.ANTHROPIC_API_KEY
    } : undefined
  };
}

/**
 * Get configuration for a specific SMRT object
 */
export function getSmrtConfig(className: string): SmrtClassOptions {
  const defaults = getDefaultConfig();
  const override = objectOverrides[className];

  if (override) {
    return {
      ...defaults,
      ...override,
      db: override.db ? { ...defaults.db, ...override.db } : defaults.db,
      ai: override.ai !== undefined ? override.ai : defaults.ai
    };
  }

  return defaults;
}

/**
 * Helper to get a collection with centralized configuration
 */
export async function getCollection<T>(className: string) {
  return await ObjectRegistry.getCollection<T>(
    className,
    getSmrtConfig(className)
  );
}
```

## Custom Actions

Custom methods on SMRT objects become REST endpoints.

### Defining Custom Actions

```typescript
@smrt({
  api: {
    include: ['list', 'get', 'create', 'analyze', 'summarize'],
    exclude: ['delete']
  }
})
class Document extends SmrtObject {
  title: string = '';
  content: string = '';

  // Custom action methods
  async analyze(options: any = {}) {
    const analysisType = options.type || 'general';
    return {
      action: 'analyze',
      type: analysisType,
      results: await this.performAnalysis(analysisType),
      timestamp: new Date()
    };
  }

  async summarize(options: any = {}) {
    const length = options.length || 'medium';
    return {
      action: 'summarize',
      summary: await this.ai.message(`Summarize: ${this.content}`),
      length,
      timestamp: new Date()
    };
  }
}
```

### Generated Custom Action Routes

**Generated structure:**
```
src/routes/api/documents/
├── +server.ts                    # Standard collection routes
├── [id]/
│   ├── +server.ts               # Standard item routes
│   ├── analyze/
│   │   └── +server.ts          # POST /api/documents/:id/analyze
│   └── summarize/
│       └── +server.ts          # POST /api/documents/:id/summarize
```

**Generated route handler:**
```typescript
// src/routes/api/documents/[id]/analyze/+server.ts
import { json, error } from '@sveltejs/kit';
import type { RequestHandler } from './$types';
import { getCollection } from '$lib/server/smrt';

export const POST: RequestHandler = async ({ params, request }) => {
  const collection = await getCollection('Document');
  const item = await collection.get(params.id);
  if (!item) throw error(404, 'Document not found');

  const options = await request.json();
  const result = await item.analyze(options);

  return json({ action: 'analyze', result });
};
```

### Using Custom Actions

**From frontend:**
```typescript
// Analyze document
const response = await fetch('/api/documents/doc-123/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    type: 'detailed',
    criteria: ['quality', 'grammar']
  })
});

const { action, result } = await response.json();
console.log(result);
```

**From server:**
```typescript
import { getCollection } from '$lib/server/smrt';

const collection = await getCollection('Document');
const doc = await collection.get('doc-123');
const analysis = await doc.analyze({ type: 'detailed' });
```

## Development Workflow

### Initial Setup

1. **Install dependencies:**
   ```bash
   pnpm install
   ```

2. **Configure plugin** in `vite.config.ts`

3. **Create SMRT objects** in `src/lib/smrt/`

4. **Start dev server:**
   ```bash
   pnpm dev
   ```

5. **Routes auto-generate** on first run and when files change

### Hot Module Replacement

The plugin supports HMR - routes regenerate automatically when:
- SMRT object files change
- Decorator configuration changes
- New objects are added
- Objects are removed

**Note:** Configuration file (`src/lib/server/smrt.ts`) is only generated once to preserve customizations.

### Generated Files

**Auto-generated (don't edit):**
```
src/routes/api/
└── <objects>/
    ├── +server.ts           # ⚠️ Auto-generated
    └── [id]/
        └── +server.ts       # ⚠️ Auto-generated
```

**User-editable:**
```
src/lib/server/
└── smrt.ts                  # ✅ Edit for configuration
```

### .gitignore

The plugin automatically updates `.gitignore`:

```gitignore
# SMRT auto-generated routes (from Vite plugin)
src/routes/api/**/+server.ts
```

**Custom routes** - To add custom route logic alongside generated routes:
```
src/routes/api/documents/
├── +server.ts               # Auto-generated
├── custom/
│   └── +server.ts          # Your custom route (committed)
└── [id]/
    ├── +server.ts          # Auto-generated
    └── custom/
        └── +server.ts      # Your custom route (committed)
```

## Examples

### Example 1: Blog API

**Define objects:**
```typescript
// src/lib/smrt/Post.ts
@smrt({
  api: {
    include: ['list', 'get', 'create', 'update', 'publish'],
    exclude: ['delete']  // Soft delete instead
  }
})
class Post extends SmrtObject {
  title: string = '';
  content: string = '';
  status: 'draft' | 'published' = 'draft';
  publishedAt?: Date;

  async publish(options: any = {}) {
    this.status = 'published';
    this.publishedAt = new Date();
    await this.save();
    return { published: true, publishedAt: this.publishedAt };
  }
}

// src/lib/smrt/Comment.ts
@smrt({ api: true })
class Comment extends SmrtObject {
  postId: string = '';
  author: string = '';
  content: string = '';
}
```

**Generated API:**
```
/api/posts              GET (list), POST (create)
/api/posts/:id          GET, PUT
/api/posts/:id/publish  POST (custom action)
/api/comments           GET (list), POST (create)
/api/comments/:id       GET, PUT, DELETE
```

### Example 2: Multi-Database Setup

**Configuration:**
```typescript
// src/lib/server/smrt.ts
const objectOverrides: Record<string, Partial<SmrtClassOptions>> = {

```

### Example 3: Custom Action with Validation

**SMRT object:**
```typescript
@smrt({
  api: {
    include: ['list', 'get', 'create', 'analyze', 'export'],
    exclude: ['update', 'delete']
  }
})
class Report extends SmrtObject {
  title: string = '';
  data: any = {};
  status: 'pending' | 'complete' = 'pending';

  async analyze(options: any = {}) {
    // Validate options
    if (!options.metrics || !Array.isArray(options.metrics)) {
      throw new Error('metrics array required');
    }

    // Perform analysis
    const results = await this.performAnalysis(options.metrics);

    // Update status
    this.status = 'complete';
    await this.save();

    return {
      action: 'analyze',
      metrics: options.metrics,
      results,
      completedAt: new Date()
    };
  }

  async export(options: any = {}) {
    const format = options.format || 'json';

    if (format === 'csv') {
      return {
        action: 'export',
        format: 'csv',
        data: this.convertToCSV()
      };
    }

    return {
      action: 'export',
      format: 'json',
      data: this.data
    };
  }
}
```

**Usage:**
```typescript
// Analyze report
const response = await fetch('/api/reports/report-123/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    metrics: ['views', 'engagement', 'conversion']
  })
});

// Export report as CSV
const csvResponse = await fetch('/api/reports/report-123/export', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ format: 'csv' })
});
```

## Troubleshooting

### Routes not generating

**Check:**
1. Plugin configured in `vite.config.ts`
2. SMRT objects have `@smrt()` decorator
3. Files match `include` patterns
4. Dev server is running

**Debug:**
```typescript
// Enable debug logging
import { smrtPlugin } from '@have/smrt/vite-plugin';

smrtPlugin({
  include: ['src/lib/smrt/**/*.ts'],
  debug: true  // Enable verbose logging
})
```

### Import errors in generated routes

**Problem:** `Cannot find module '$lib/server/smrt'`

**Solution:** Ensure configuration file exists at `src/lib/server/smrt.ts`

### Type errors in generated routes

**Problem:** `Property 'analyze' does not exist`

**Solution:**
1. Restart dev server to regenerate types
2. Ensure method is public (not private/protected)
3. Check TypeScript declaration generation is enabled

### Custom actions not appearing

**Check:**
1. Method is async and public
2. Method name included in `api.include` array
3. Method name not in `api.exclude` array
4. Method exists on the class (not inherited privately)

### Configuration changes not applying

**Solution:** Restart dev server - configuration file is only generated once

## Best Practices

### 1. Organize SMRT Objects

```
src/lib/smrt/
├── core/           # Core domain objects
│   ├── User.ts
│   └── Account.ts
├── content/        # Content management
│   ├── Post.ts
│   └── Comment.ts
└── analytics/      # Analytics objects
    ├── PageView.ts
    └── Event.ts
```

### 2. Use Consistent Naming

```typescript
// Class name (PascalCase)
class BlogPost extends SmrtObject { }

// Generated routes
/api/blog-posts  // Kebab-case, pluralized

// Collection name
const blogPosts = await getCollection('BlogPost');
```

### 3. Document Custom Actions

```typescript
@smrt({ api: { include: ['analyze', 'export'] } })
class Report extends SmrtObject {
  /**
   * Analyze report data
   * @param options.metrics - Metrics to analyze (required)
   * @param options.period - Time period for analysis
   * @returns Analysis results with metrics and insights
   */
  async analyze(options: any = {}) {
    // Implementation
  }
}
```

### 4. Handle Errors Gracefully

```typescript
async customAction(options: any = {}) {
  try {
    // Validate inputs
    if (!options.required) {
      throw new Error('Required field missing');
    }

    // Perform action
    const result = await this.performWork(options);

    return { success: true, result };
  } catch (error) {
    return {
      success: false,
      error: error instanceof Error ? error.message : 'Unknown error'
    };
  }
}
```

### 5. Use Environment-Specific Configuration

```typescript
function getDefaultConfig(): SmrtClassOptions {
  const isDev = process.env.NODE_ENV === 'development';

  return {
    db: {
      url: isDev
        ? ':memory:'  // In-memory for development
        : process.env.DATABASE_URL!,
      type: 'sqlite'
    },
    ai: isDev
      ? undefined  // Skip AI in development
      : {
          type: 'openai',
          apiKey: process.env.OPENAI_API_KEY!
        }
  };
}
```

## Security Considerations

### 1. Authentication

Generated routes don't include authentication - add middleware:

```typescript
// src/hooks.server.ts
import type { Handle } from '@sveltejs/kit';

export const handle: Handle = async ({ event, resolve }) => {
  // Protect API routes
  if (event.url.pathname.startsWith('/api/')) {
    const session = await getSession(event.cookies);
    if (!session) {
      return new Response('Unauthorized', { status: 401 });
    }
  }

  return resolve(event);
};
```

### 2. Input Validation

Validate custom action inputs:

```typescript
async customAction(options: any = {}) {
  // Validate schema
  const schema = z.object({
    field: z.string().min(1).max(100),
    count: z.number().int().min(0).max(1000)
  });

  const validated = schema.parse(options);
  // Use validated data
}
```

### 3. Rate Limiting

Add rate limiting middleware for API routes.

### 4. Sensitive Data

Exclude sensitive operations from API:

```typescript
@smrt({
  api: {
    include: ['list', 'get'],  // Read-only API
    exclude: ['create', 'update', 'delete']
  }
})
class SensitiveData extends SmrtObject { }
```
