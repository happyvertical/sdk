# Local semantic segmentation

`@happyvertical/images/segmentation` is an optional browser entry point. It does not import Node image adapters. `segmentImage(ImageData, { assetBaseUrl, signal, onProgress })` runs the pinned MediaPipe 1.1.0 CPU runtime locally; no photo is uploaded. `segmentationAlpha(result, { classes, lower, upper, largestComponent })` converts semantic probabilities into a soft alpha mask. It does not alter original RGB channels. Select classes as consumer policy; the SDK does not define a head or portrait workflow.

`detectFaceLandmarks(HTMLImageElement, options)` runs the pinned FaceLandmarker model locally and returns one face's outer lip corners and chin in 0–1000 image coordinates. It rejects zero or multiple faces and never substitutes an estimated facial line.

Before serving this optional feature, run `pnpm --filter @happyvertical/images prepare:segmentation`. It downloads the version-1 selfie multiclass model (SHA256 `c6748b1253a99067ef71f7e26ca71096cd449baefa8f101900ea23016507e0e0`) and FaceLandmarker task model (SHA256 `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`), then copies the installed runtime WASM files into `segmentation-assets/`. Serve these files from a same-origin path with immutable cache headers; the Node-only `segmentationAssetPath(name)` export validates the fixed asset allowlist. Prepared assets work without external network access. Browser model loading independently verifies the digest and uses its HTTP cache. The runtime and models are Apache-2.0 licensed: [runtime license](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE). Distributors must preserve the Apache license and attribution for bundled third-party assets.

Classes: background 0, hair 1, body skin 2, face skin 3, clothes 4, accessories 5. The model has a 256×256 internal resolution; output confidence masks are aligned to input dimensions. It is not a pixel-perfect hair matting model. The caller should expose review/retry rather than silently accept uncertain contours. Input is capped at 16 megapixels to bound mask memory. Cancellation is checked during loading and before/after synchronous inference; inference itself cannot be interrupted once started.

## Test design and validation

| Behavior/invariant | Trigger and cases | Context and external edge | Test level and evidence |
| --- | --- | --- | --- |
| Semantic alpha preserves selected foreground only | Combine selected classes; reject duplicate/missing classes, invalid dimensions, probabilities, thresholds, and empty masks | Browser-local pure mask processing; no transaction or dialect applies | Unit: `pnpm --filter @happyvertical/images test` |
| Alpha selection remains visually coherent | Retain the largest 8-connected region while preserving soft confidence alpha | Consumer chooses classes; the SDK deliberately has no portrait policy | Unit: `pnpm --filter @happyvertical/images test` |
| Original RGB bytes survive transparent PNG export | Encode fully transparent, partially transparent, and opaque pixels; reject malformed buffers | Browser `CompressionStream`; no network or persistence applies | Unit: `pnpm --filter @happyvertical/images test` |
| Model is local, pinned, and verified before use | Abort before fetch; reject a digest mismatch; retry a failed load in the consumer | Same-origin model and WASM assets; upstream or HTTP failure surfaces as an error | Unit for abort/integrity: `pnpm --filter @happyvertical/images test`; browser acceptance for load/retry |
| Face mesh maps only a complete single face | Map lip/chin indices into normalized coordinates; reject incomplete, zero, or multiple faces | Browser-local detector; no provider, transaction, or dialect applies | Unit mapping and lifecycle tests verify ambiguity rejection and task cleanup: `pnpm --filter @happyvertical/images test` |
| Face runtime fails closed and releases resources | Reject a bad model digest before runtime initialization; abort after initialization; make detector throw | The detector task closes on every post-creation exit and never estimates landmarks | Unit: `pnpm --filter @happyvertical/images test` |
| Private photo remains local and reviewable | Run the consumer’s real-photo flow, inspect head boundary and RGB output, then cancel/retry without stale UI writes | User-owned private photo; it is excluded from source control, issue evidence, and release artifacts | Browser acceptance performed privately; no photo or derived output retained in this repository |

Run `pnpm --filter @happyvertical/images test` and `pnpm --filter @happyvertical/images build`. The browser acceptance row requires a real photo, original RGB preservation, explicit load failure/retry, and cancellation without stale UI writes; do not check private photos into the repository.
