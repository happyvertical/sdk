# Happy Vertical SDK

TypeScript packages for building AI-powered applications.

## Packages

- **[@have/ai](/docs/supporting-libraries/ai)** - Multi-provider AI client with builtin adapters for OpenAI, Anthropic, Gemini, Bedrock, HuggingFace
- **[@have/cache](/docs/supporting-libraries/cache)** - Caching interface with builtin adapters for Memory, File, Redis
- **[@have/config](/docs/supporting-libraries/config)** - Configuration management
- **[@have/documents](/docs/supporting-libraries/documents)** - Document processing for PDFs, HTML, and Markdown
- **[@have/files](/docs/supporting-libraries/files)** - File system operations with local and remote provider support
- **[@have/geo](/docs/supporting-libraries/geo)** - Geographic utilities and services
- **[@have/logger](/docs/supporting-libraries/logger)** - Logging infrastructure
- **[@have/ocr](/docs/supporting-libraries/ocr)** - OCR interface with builtin adapters for Tesseract, ONNX, Web OCR
- **[@have/pdf](/docs/supporting-libraries/pdf)** - PDF parsing and text extraction
- **[@have/spider](/docs/supporting-libraries/spider)** - Web crawling with builtin adapters for Simple, DOM, Crawlee
- **[@have/sql](/docs/supporting-libraries/sql)** - Database interface with builtin adapters for SQLite, PostgreSQL, DuckDB, JSON
- **[@have/translator](/docs/supporting-libraries/translator)** - Translation services integration
- **[@have/utils](/docs/supporting-libraries/utils)** - Shared utilities and helpers
